# 统一评分标准

本项目采用 **50% 核心验收完成分＋50% 整题严格通过奖励**。单题总分上限按发布前冻结的难度权重确定：E=1、M=2、H=3。

- [统一评分标准 v1.0](统一评分标准_v1.0.md)：指标定义、固定分母、独立运行验收、Reward、汇总与版本迁移。
- [机器可读规则](reward-policy-v1.0.json)：公式、占比、显示名称和实施状态。
- [合成计分示例](examples-v1.0.json)：部分完成、严格通过、公开检查失败、完整性失败和可选稳健性失败。
- [校验摘要](SHA256SUMS)。

**状态：评分规范已采纳；已有数据包中的旧评分器尚未因本文发布而自动迁移。** 新规则实施必须另行冻结评分器、检查清单及摘要，并使用独立版本保存重评分结果。不要将旧比例分或仅改变权重的历史换算称为已完成新版严格验收。

任务说明、输入、业务算法、接口契约及原始历史成绩均保留。公开通过、核心转换用例通过率和严格通过率分别报告；Reward 不等于其中任一通过率。
