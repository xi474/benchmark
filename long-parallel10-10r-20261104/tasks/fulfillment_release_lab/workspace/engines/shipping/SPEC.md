Every mandatory client must be covered. Optimize maximum sum covered client weights (count client once); minimum cost; maximum covered client count; minimum chosen window count; minimum sorted selected-ID list. Return {feasible,value,cost,selected,completion:{client_id:earliest_end}}; completion contains exactly covered clients; selected sorted. Infeasible false,0,0,[],{}.
