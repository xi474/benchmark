All integers are nonnegative unless explicitly stated otherwise. Reject NaN/Infinity anywhere, including extra fields. Extra fields may be ignored after finite-value validation. normalize returns a new canonical object containing only specified fields: record lists sorted by id, ID lists sorted and unique, nested effect/contents lists sorted by their reference key. No input or contract mutation. Both normalize(payload) and solve(payload, contract) independently accept and validate raw input. The contract object is file/API metadata, not business input. Use an exact algorithm for bounded input sizes. Return the bare result object with exactly the specified keys, types, ordering and tie rules; no name/result envelope.

For valid payload it must accept a correct result and reject malformed, infeasible or numerically inconsistent results. It must recompute feasibility and totals from input and the proposed decision, rather than unconditionally accepting, trusting totals, or simply delegating to solve. It need not prove global optimality: focused and final tests separately compare solve against exact optima. For invalid payload it raises ValueError; malformed result returns False. It must not mutate input/result/contract. All APIs use only the Python standard library.

Input {crew_capacity,power_capacity,jobs:[{id,start,end,crew,power,priority,risk,deps:[job_id]}]}; at most 15 jobs. crew>=1, end>start. deps are known job IDs, no self edge or cycle. Selecting a job requires selecting all its prerequisites, but deps does not impose extra timing rules. At every t, selected jobs with start<=t<end consume crew and power simultaneously; sums cannot exceed capacities. End releases before start at the same time. Exposure=sum(risk*(end-start)). Optimize, in order: maximum sum priority; minimum exposure; maximum selected count; minimum sorted selected-ID list lexicographically. Zero-priority jobs still affect tie rules. Return {score,exposure,selected,rejected}; lists sorted, disjoint, covering all jobs. Empty selection allowed.
