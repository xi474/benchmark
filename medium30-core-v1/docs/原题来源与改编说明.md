# 原30题的来源与改编说明

范围为medium30-core-v1的N01–N30，共30道改编任务、31个不同源实例。任务数：SWE-bench Verified 11、SWE-bench Pro 8、Terminal-Bench 7、GAIA2 4；Pro源实例为9个，因为N15组合了两个Ansible源题。

这份说明补充原有review/source_annotations.json，逐题说明原问题、改编范围、源实例链接、固定版本和原始标签。仅补文档与追溯索引，不改变题面、输入、参考解、verifier、评分或已有成绩。

## 如何理解原始难度

- SWE-bench Verified：原字段为人工预计修复时长，不能换算成模型通过率。
- SWE-bench Pro：保留HARD51成员标志；hard=false不代表简单或中等。
- Terminal-Bench：保留固定task.toml中的作者easy/medium标签及预计工时，不冒充逐题多次实测档位。
- GAIA2：所选场景没有逐题难度；category是场景类别，不是GAIA 1的Level 1/2/3。

原始数据的逐题统一模型通过率未核验，保持null；不能用整体排行榜代填。我们自己的M设计目标和后续实测档位另行记录，不从上游标签直接继承。

## 版本与证据

数据集data_revision、上游题库Git版本、修复前base_commit是不同概念，分别保留。SWE/Pro/GAIA2核对冻结Parquet对应行；Terminal核对原task.toml及其Git文件SHA。本次只发布元数据与中文转述，不复制上游完整测试补丁、Oracle事件或问题长文本。原始本地证据SHA保留；同名原始证据不在本仓库中，并未把新摘要冒充相同字节。
