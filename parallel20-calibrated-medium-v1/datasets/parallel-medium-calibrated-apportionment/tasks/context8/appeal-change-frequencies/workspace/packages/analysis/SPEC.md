# Award probabilities after an allocation appeal

rows and cols are objects mapping names to integer totals. Each item in cells is {id,row,col,quota:[numerator,positive_denominator],published}. Each existing cell belongs to one row and one column and holds exactly its floor or ceiling quota in integer units. Each row/column pair occurs at most once. An absent cell cannot receive awards. The published table meets every margin and all cell bounds. Quotas are nonnegative. Instances contain at most 12 rows and 12 columns, and in each row and column the extra units above all cell floors sum to at most two.

Each item of appeals is {id,fix}, where fix maps cell IDs to the integer awards requested for that review. Assess each appeal independently. A revision must obey these fixed entries, both sets of totals and the quota bounds. Among feasible revisions first minimize total absolute deviation of the awards from their quotas. Among the revisions attaining that minimum, minimize the number of cells changed from the published table. The review board samples uniformly from all tables achieving both minima. Different assignments to cell IDs are different tables. Each table counts once, irrespective of how it was constructed.

Return {appeals:{appeal_id:result}}. If no feasible revision exists, return null for that appeal. Otherwise result is {loss,changes,tables,changed_in}. loss is the minimum absolute deviation as an integer numerator and positive denominator pair, with equivalent fractions accepted. changes is the secondary minimum. tables is the exact integer number of distinct equally optimal revisions. changed_in maps EVERY existing cell ID to the integer number of those tables in which its award differs from publication, including zero. The probability of a changed award is that count divided by tables.
