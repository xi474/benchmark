# Timing closure with shared clocks and path exceptions

nodes and directed edges {id,from,to} form an acyclic data circuit. launch_clock maps data sources to ordered lists of physical clock segments. endpoints maps data endpoints to {capture_clock,period,setup,hold}. Clock paths are root-to-leaf paths in one physical clock tree. A given segment ID represents the same wire wherever it occurs. All node delays are included in the data edge intervals. forbidden is a list of nonempty contiguous words of data node IDs; disallow any source-to-endpoint data path containing such a word.

Each operating corner gives clock (segment ID to [min,max] delay) and data (edge ID to [min,max] delay). A complete timing measurement uses one corner throughout. In that corner assign each physical clock segment a single value in its interval, shared by launch and capture when both traverse it. Distinct segments and the traversed data edges can vary independently within their intervals. A launch or capture clock arrival is the sum along its own listed path. Data arrival D is the sum along an admissible data path. Let A be the launch clock arrival and B the capture clock arrival.

At each endpoint report the minimum setup slack, B + period - setup - A - D, and the minimum hold slack, A + D - B - hold, across admissible launch sources, data paths, corners and delays. Each minimum can have a different witness. Negative slack denotes a real timing violation. Return {slack:{endpoint:{setup,hold}}}; an endpoint with no admissible path has null instead of the pair. Input order has no physical meaning.
