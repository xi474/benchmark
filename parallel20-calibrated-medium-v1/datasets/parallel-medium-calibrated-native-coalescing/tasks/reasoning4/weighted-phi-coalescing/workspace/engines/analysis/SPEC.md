# Complete CFG liveness and minimum-cost spilling

This is a finite synthetic single-assignment CFG model, not a real ISA. Input contains config,cfg,spill_cost,edge_frequency. edge_frequency has exactly one {pred,succ,frequency} row per CFG edge, with integer frequency1–100; it is an execution-count weight, not an imposed processing order. config is {registers,call_clobbered,precolors}: up to four distinct register names, a subset clobbered by every call, and a map of pinned variables to registers. cfg is {entry,parameters,blocks}. Each block is {id,successors,phis,instructions}; each phi is {def,inputs}, where inputs maps EXACTLY the block's predecessor IDs to incoming variable IDs. Each instruction is {id,uses,def,call}; def may be null, uses is a list of globally defined variables, call a boolean. Variables are parameters or exactly one phi/instruction definition. There are at most 22 variables and 8 reachable blocks; branches and backedges are allowed. Every variable, including unused definitions, has one strictly positive integer spill_cost. Data is well formed. Phi references may point to variables defined later in array order. No additional dominance-validity test or malformed-input behavior is required. Block/phi/successor order is irrelevant; instruction order WITHIN a block matters.

For block B let phi_defs[B] be phi definitions. Traverse instructions forward with those definitions already seen. use[B] contains instruction-used variables not previously defined in B; defined[B] contains phi and instruction definitions. Let edge_use(B,S) contain successor S's phi inputs selected by predecessor B. Solve the LEAST fixed point:
out[B] = union over successors S of ((in[S] minus phi_defs[S]) union edge_use(B,S));
in[B] = use[B] union (out[B] minus defined[B]).
Phi incoming values are predecessor-edge uses, not ordinary successor uses. Return live_in/live_out for EVERY block, as variable sets represented by lists.

Compute conservative undirected interference. For each block start live=out[B] and add edges for all pairs in live. Traverse instructions backwards. At a call, forbid every call_clobbered register for every variable in live_after EXCEPT that instruction's own definition. For a non-null definition d, add edges d--v for every other v in live_after, then remove d. Add all instruction uses to live and all pairs in this updated live. After the instructions add all pairs in that live set and in in[B]. Ignore self edges and duplicate edges. call_forbidden reports only nonempty variable-to-register sets. All variables still require a location.

Pinned variables may not spill. If any pinned register is call-forbidden, status is UNSAT_PRECOLOR and reason PRECOLOR_CALL_CLOBBER. Otherwise if an interfering pinned pair uses the same register, status is UNSAT_PRECOLOR and reason PRECOLOR_INTERFERENCE. This priority is part of the original business model. Still report dataflow/interference, but min_spill:null,copy_cost:null,locations:{},spills:[],edge_moves:[].

Otherwise choose, for each variable, a register or spill. Interfering register-resident variables cannot share a register; no variable may use a forbidden register; honor every precolor. Minimize SUM(spill_cost[v] for spilled v) EXACTLY. This replaces the source task's greedy degree/ID allocation; there is NO greedy or ID tie-break. Among all allocations with the MINIMUM spill cost, MINIMIZE copy_cost: for EVERY CFG edge, count phi moves with unequal source/destination locations, multiplied by that edge frequency, then sum across all edges. Each differing phi counts separately, even if two moves share locations; a parallel cycle needs no additional charged move beyond its phi assignments. Copies between distinct logical spill slots are unequal locations. Spill cost is the PRIMARY objective, copy_cost SECONDARY. Return ANY allocation tied on BOTH objectives. Minimizing unweighted move count or optimizing copies only after choosing an arbitrary minimum-spill allocation is insufficient. Locations map EVERY variable to 'reg:REGISTER' or, if spilled, 'spill:VARIABLE'. Each spill has its own logical slot; slot reuse, machine code, loads/stores and sequential copy scheduling are outside this task. spills lists exactly the spilled variable IDs; min_spill is their integer cost.

For EVERY CFG edge pred->succ, report {pred,succ,moves,cycle}. Each phi in succ has destination phi.def and source phi.inputs[pred]. If their returned locations differ include {definition:destination_variable,source:source_variable,from_location:source_location,to_location:destination_location}; equal locations require no move. All these moves are parallel. cycle is true exactly when the directed graph of DISTINCT from_location->to_location transitions contains a directed cycle. Empty edges still appear. The certificate must match YOUR chosen optimal allocation, not an arbitrary reference coloring.

Output exactly {status,reason,live_in,live_out,interference,call_forbidden,min_spill,copy_cost,locations,spills,edge_moves}. Feasible status is ALLOCATED with reason:null. interference is a list of two-variable edges; all set/list/map order is immaterial. Equivalent optimal colorings are accepted after their legality and their own copy certificates are checked.

Public example is one block defining a,b, using a, defining c, using b, using c, so interference is a--b--c. With one register and spill costs a:5,b:8,c:5, globally keep a,c and spill b at cost8. Keeping the highest-degree or highest-weight b costs10 in other spills. With two registers the minimum is0. A phi edge with incoming a in R0 and b in R1, destinations x in R1 and y in R0, has two parallel moves forming a cycle; it is not two independent sequential assignments.

Additional public example: E branches to P and Q, both lead to M. Parameters a/b are pinned to R0/R1. M has phi x(P:a,Q:b) and y(P:b,Q:a); x and y are used together. Every spill cost1. Frequencies P->M=1, Q->M=3 (other edges1). min_spill0 and copy_cost2: assign x=R1,y=R0 and do two cold-edge parallel moves. Assigning x=R0,y=R1 is equally valid for spill and has the same unweighted move count, but copy_cost6 and is not optimal. Reversing the two frequencies reverses the preferred allocation.
