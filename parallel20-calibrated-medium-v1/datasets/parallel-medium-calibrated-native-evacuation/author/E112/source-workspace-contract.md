# Synthetic wildfire evacuation grid

Implement `python -m project.cli INPUT.json OUTPUT.json` preserving input bytes and writing deterministic compact sorted-key JSON plus final newline. This is a toy grid simulation, not a real emergency plan.

Input has `grid` rows of equal width, `#` walls and `.` traversable cells; shelters and evacuees may occupy any traversable coordinate. `spread_cost` is a same-shaped positive integer matrix; the fire needs `spread_cost[target]` ticks to enter a neighboring cell. `fire_seeds` list `r,c,time`; several seeds may ignite at different times. Fire ignores road closures and spreads through all nonwall cells by orthogonal moves. The earliest ignition time at each cell is the minimum weighted path time from any seed. For walls or never-reached cells output null.

`closures` list `r,c,start,end` with both endpoints inclusive. A closure forbids **occupying** that cell at a blocked time, including waiting there; overlapping intervals combine by OR. Evacuees have unique `id,r,c,release`, shelters unique `id,r,c,opens,closes,capacity`. Traveler moves one orthogonal cell each tick or waits in place. Occupied cell at time `t` must be traversable, not closed and have no fire arrival at or before `t` (strict `t < fire_arrival`). The starting cell at release must also pass this rule. A shelter accepts arrival only when `opens <= t < closes` and has unused capacity. Each successful assignment consumes one capacity slot, but travelers otherwise do not block one another.

Process evacuees by `(release,id)`. For each, choose the earliest feasible shelter arrival no later than `max_ticks`; tie-break by shelter ID and then lexicographically smallest coordinate path, where path lists one `[r,c]` at each tick from release through arrival inclusive. An unassigned evacuee has `status:"unassigned"`, null shelter/arrival and empty path. Assigned rows include `id,status:"assigned",shelter,arrival,path` in processing order. Output `fire_arrival` matrix, `evacuees`, shelters sorted by ID as `id,used,capacity`, and audit with assigned/unassigned counts and `capacity_respected`, which checks every emitted route, safety and capacity. Public fixture and hidden cross-module cases vary spread costs, closures, shelter windows, capacity competition and strict fire boundaries. The Agent may choose its own workflow.
