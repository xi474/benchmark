# Synthetic CAD tolerance stack-up

Implement `/app/workspace/project` so `python -m project.cli input.json output.json` works. All dimensions use integer units. Input has `variables` (1–9), `assemblies` (0–12), and `queries` (0–8). A variable is `{id,nominal,minus,plus}`, with integer nominal and nonnegative integer minus/plus; its permissible interval is `[nominal-minus,nominal+plus]`. An assembly is `{id,offset,terms}` where each term is `{ref,coefficient}` with integer coefficient -3..3 referring to a variable or another assembly. Assembly values are `offset+sum(coefficient*ref_value)`. Assembly references form a DAG, and all IDs across variables/assemblies are unique. A query is `{id,left,right,required_min,required_max}` with unique ID and required_min<=required_max. Its clearance is `left_value-right_value`. Query refs exist. Arrays may be in any order and terms may repeat the same ref.

Expand each query clearance into a single integer constant plus a coefficient for each **original variable**, combining repeated/shared variable references before taking extremes. In particular, if the same uncertain variable appears on both sides, its effects can cancel; do not optimize each assembly interval independently. `nominal` evaluates all variables at their nominal values. `min` and `max` are exact extrema over all independent variable intervals. For each extremum, output a witness assignment for **every** variable sorted by ID. At a nonzero net coefficient, choose the interval endpoint minimizing/maximizing clearance; for zero net coefficient, choose the variable's **lower** endpoint for both witnesses. `coefficients` lists only nonzero net coefficients, sorted by variable ID as `{variable,coefficient}`.

Fit classification: `guaranteed_fit` iff the full `[min,max]` lies in inclusive `[required_min,required_max]`; otherwise `possible_fit` iff the intervals intersect; otherwise `no_fit`. Output `{queries:[...]}` sorted by query ID. Each row is `{id,nominal,min,max,fit,coefficients,min_assignment,max_assignment}`, where assignment arrays have `{variable,value}`. Serialize sorted object keys, compact JSON and final newline; do not modify input. Standard library only. Hidden cases include shared-variable cancellation, repeated terms, nested assemblies, asymmetric tolerances, negative coefficients and fit boundaries. No Agent workflow is required.
