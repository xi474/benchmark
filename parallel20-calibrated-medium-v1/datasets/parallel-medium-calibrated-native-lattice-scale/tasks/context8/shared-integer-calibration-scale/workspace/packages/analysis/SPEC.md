# Shared calibration and quantized assembly tolerances

All displacements are integers in the inclusive intervals given by bounds, a dictionary from datum names to [minimum,maximum]. There are 2–8 datums, at most nine possible integer positions per datum, 1–3 readout boards with 1–3 settings each, 1–3 installation setups, and 1–3 gauges. All coefficients, offsets, raw readings and costs are finite integers. Settings have nonnegative penalty. Inputs follow this schema.

Each board in boards has id and settings. A setting has id, penalty and channels. Each channel is {coefficients:{datum:integer,...},offset:integer}. At displacement vector x it reads offset + sum(coefficients[d]*x[d]). Missing coefficients are zero. A setting supplies every channel referenced for that board. Exactly one setting is selected for each board, shared across ALL installation setups. The total penalty is the sum of those selected settings' penalties, counted once per board.

Each item in calibrations has board, channel, displacements and raw. Here displacements is a fully known calibration-piece vector. The selected board setting must predict a reading inside that item's inclusive raw:[low,high] interval. Calibration pieces serve only as known observations; installation physical constraints are not imposed on them.

Each row of physical_constraints is {coefficients:{datum:integer,...},min:integer,max:integer}, requiring min <= sum(coefficients[d]*x[d]) <= max. Each item of setups has id, constraints (additional rows in the same format), and readings. An installation reading is {board,channel,raw:[low,high]}. For each setup there must exist an integer displacement vector in bounds satisfying its constraints, the common physical_constraints, and all its readings under the shared board settings. Different setups may use different displacement vectors. All setups must be feasible for ONE common selection of board settings. Installing a different setting for each setup is not allowed.

Among such selections minimize total penalty. Retain ALL setting selections with this minimum penalty. For each board report the IDs of all its settings occurring in at least one globally optimal selection. Each gauge has id, base, coefficients; its value is base + sum(coefficients[d]*x[d]). For each setup and gauge compute the minimum and maximum attainable integer gauge value over all globally optimal setting selections and all of that setup's feasible displacement vectors. Different extrema may be attained with different optimal selections and vectors. Other setups must remain feasible under any selection contributing to a range.

Return {minimum_cost:integer,setting_options:{board:[setting_id,...]},ranges:{setup:{gauge:[minimum,maximum]}}}. Setting ID order is immaterial. If no shared selection makes every setup feasible, return {minimum_cost:null,setting_options:{},ranges:{}}. All references, channel IDs and datum names in a request are valid. Every supplied setting is a candidate, even if it has the same penalty or coefficients as another setting.

In the public example s1 alone admits a0+b0 at cost 0 and has sum range [2,2]. With s2 also required, a0 would require 2*x=1 in s2 and is impossible on the integer lattice. Both a1+b0 and a2+b0 attain the global cost 1. Thus the full request has setting_options A:[a1,a2], B:[b0]; s1 has sum:[2,3], difference:[0,1]; s2 has sum:[1,2], difference:[-1,0]. Continuous relaxation or rounding a continuous extremum does not define the requested integer extrema.

Normal workload limit: the product over datum interval lengths (maximum-minimum+1) is at most2,000,000. Each individual interval may still contain up to nine integer positions. All shared board settings, all-installation feasibility, all-optimal selections and exact integer gauge extrema remain required.
