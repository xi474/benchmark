# Synthetic port container yard

Implement `python -m project.cli INPUT.json OUTPUT.json`. Preserve input bytes and emit compact sorted-key JSON plus final newline. This is a fictional rule system, not port operating guidance.

Input: `containers` unique id,hazard,integer appointment_tick; `stacks` unique id,capacity nonnegative integer,allowed_hazards list,containers list **bottom to top**; directed `links` from,to stack IDs; `move_budget_per_tick` nonnegative integer; `requests` unique id,integer tick,container. All references resolve, initial every container is on exactly one stack, and initial stack capacities and hazards are valid. Links do not self-loop. Input arrays may be unsorted. Multiple requests may target the same container; after accepted retrieval it is no longer in the yard.

Replay requests sorted `(tick,request ID)`. If the target is not on any stack, reject `already_retrieved`. Otherwise if request tick < target appointment_tick, reject `too_early`. Otherwise plan retrieval on a private copy of current stacks. If target is buried, take the current top blocker and move it from target's stack to another stack with a directed link from source, free capacity and the blocker's hazard allowed. Choose destination minimum `(current number of containers, destination stack ID)`. Repeat until target is on top; retrieve it. If a blocker has no legal destination, reject `blocked`. Each rehandle and final retrieval costs one move. A shared budget applies per request tick across all accepted requests, resetting at a new tick. If planned moves exceed remaining budget, reject `move_budget`. Rejected requests change neither stacks nor budget. On acceptance record dwell=request.tick-appointment_tick.

Output events in replay order, each id,accepted,reason (`ok` on acceptance),rehandles list in move order (`container,from,to`),moves count,dwell integer or null on rejection. `stacks` sorted stack ID with stack,containers bottom-to-top. `delivered` sorted container ID with container,tick,dwell. Audit accepted,rejected,moves,rehandles,total_dwell,remaining_containers. Empty requests valid. Choose your own workflow.
