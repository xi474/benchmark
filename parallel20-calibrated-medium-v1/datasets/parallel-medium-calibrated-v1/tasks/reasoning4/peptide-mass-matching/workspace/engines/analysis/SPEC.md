# Synthetic peptide mass matching

This uses **invented integer residue masses** and is a toy string/matching problem, not proteomics inference. Input `proteins` (1–3) each `{id,sequence}` with unique nonempty ASCII ID and 2–8 residues drawn from `ACDEKPR`; `modifications` (0–2) each `{name,residue,shift}` with unique nonempty ASCII name, a residue from the alphabet and nonzero integer shift between -20 and 20; `spectra` (0–5) each `{id,peaks}` with unique ID and 0–8 peaks `{mass,intensity}` (integer mass>0, integer intensity>0); `tolerance` integer 0–3. Peak masses may repeat. All IDs/names contain no colon, at sign, or slash.

Toy residue masses: A=71,C=103,D=115,E=129,K=128,P=97,R=156. Digest each target protein **and its reversed-sequence decoy**. Cut after K or R unless the next residue is P, and always at the end. Emit every elementary segment of length≥2 plus every pair of adjacent segments joined (one missed cut) if length≥2. For a segment spanning one-based inclusive positions `start-end` in the respective target/decoy sequence, emit unmodified variant, plus each allowed modification at each position whose residue matches. At most one modification per variant. Candidate ID is `{protein_id}/{target|decoy}:{start}-{end}:none` or `...:{name}@{one-based position in full sequence}`. Mod shifts add to that residue mass; all resulting masses remain positive. Targets and decoys are separate candidates even when sequences match.

For each candidate peptide of n residues, theoretical fragments are all prefix sums of length 1..n-1 and all suffix sums of length 1..n-1 (multiset, so duplicates remain separate ions). A theoretical ion may match an observed peak when absolute mass difference≤tolerance. Choose a one-to-one ion/peak matching maximizing score `(matched_count,total_matched_intensity,-total_absolute_mass_error)` lexicographically. Different ions may have equal masses but each peak can be consumed once. For each spectrum pick the candidate with best score; on score ties prefer target to decoy, then lexicographically smallest candidate ID. Score `(0,0,0)` is valid. Report winners sorted by descending score tuple, then ascending spectrum ID. Assign running decoy/target counts across this ranking; report `fdr_numerator=decoys_so_far`, `fdr_denominator=max(1,targets_so_far)` (not a q-value or scientific FDR estimate).

Output `{candidate_count,winners}`; each winner `{spectrum,candidate,kind,score:[count,intensity,negative_error],fdr_numerator,fdr_denominator}`.
