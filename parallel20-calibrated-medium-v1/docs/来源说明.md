# 来源与改编说明

17题基于项目DAG300原型启发/改编，F18/F20/S02为项目自编。源库为用户的horacezoe/DagAndCodingBench；其中部分来自本地未提交质量修订，逐题SHA与原始声明为实际版本依据。没有将这些题冒称为SWE-bench或Terminal-Bench官方题目。

原始模型难度未实测或未登记；Oracle参考解通过只能说明参考验收，不是难度标签。部分改编更换业务场景或算法核心，来源族表示设计血缘，不等于原题内容和难度原封不动。训练/测试按source_family分组，原版和加强版不可跨分区。
