# 冻结评分版本与兼容性说明

本次仅增加统一调用入口和发布索引，未改动17个原接纳子包、原判题业务用例、reward或100次成绩。每题用其自身冻结评分器；原始score、scope和哈希均可追溯。

这些批次的模块装载方式不同：早期10题的独立API探针按单文件装载engine；后期10题使用Python包导入，支持普通相对导入。早期方式存在相对导入兼容性限制。既有扩充批次导入影响审计没有发现这20题已接纳成绩因此被错误扣分；这不代表旧探针未来可接受任意合法模块组织。

因此本合集不是“统一新装载器重新评分”的实验。后续若迁移装载器或比较新harness，应另登记评分版本并保留旧成绩，不将旧原始评分悄悄替换。本次按用户要求上传既有接纳题及其原五测依据。

Agent及正式评分器仅需Python标准库；少数作者侧独立数值/MILP参考实现需要NumPy/SciPy，它们不是Agent运行依赖。
