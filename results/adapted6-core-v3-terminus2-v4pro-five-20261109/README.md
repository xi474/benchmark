## 解释与使用范围

- MP04：字段别名规范化、跨来源合并及接口实现是主要检查点。
- MP08：照片选择、未选文件保持、路径/字节对应与结果排序是主要检查点。
- MP09：区间合并、最早两场时段、群集合与采购汇合是主要检查点。
- MP10：最近联系人、餐具选择与输出排序是主要检查点。
- MP11：三路业务独立，作为并行机会充足的较易对照。
- MP24：须标注输入有效性敏感；实测难不代表高算法搜索复杂度。

标签是单一模型家族、固定harness与预算、n=5的条件实测档，不能当作跨模型绝对难度。业务输入合法性、接口与集成仍属于核心；未知额外字段稳健性独立观察。

预算：单次Agent 3600秒、累计输入+输出200万token后停止（单请求可越界）；verifier1800秒；2 CPU / 4096 MiB；四并发。任务、检查与阈值在本轮运行前冻结，旧v2运行不复用。
