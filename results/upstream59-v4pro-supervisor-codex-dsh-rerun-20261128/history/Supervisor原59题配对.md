# 官方 LangGraph Supervisor 与旧版 LangGraph 的 59 题配对对照

**审阅稿 · 2026-11-27 · Upstream59 v2.1.0 · DeepSeek V4 Pro 普通模式**

合并 6 个补跑试次后，官方 Supervisor 的正式交付表现明显更好。新版 reward 从 **47.048183/138 提高至 115.075909/138**，核心 API 通过率从 **47.57% 提高至 93.03%**，严格通过从 **18/59 提高至 44/59**。代价是全部题位的平均完整 E2E 增加 **84.8%**、总 tokens 增加 **63.2%**、统一峰时估算成本增加 **22.7%**。

旧版的调度器在 **59/59 题**启动了实际工作的 Worker，共 **218 个**，均有独立模型响应。官方 Supervisor 在 **0/59 题**启动子 Agent。两版同时存在角色分工、上下文组织和单次输出上限差异，这组历史配对可以比较整套配置的表现，无法估计子 Agent 对准确率的单独因果效应。

## 配对口径

- 每个冻结题号在每侧选一个试次。旧版主基线沿用此前发布的 59 题 Planner／Worker 矩阵，由 30 个 v2.1 新试次、25 个按发布口径离线复核的历史 MP 试次、4 个复用的 N 题试次组成。
- 官方侧选入 R2 的 52 个试次、已验收的 C031 和 R3 的 6 个补跑试次。被替换的六个 attempt 仍有独立记录。先前的官方试点和旧版 runner 补丁试次也保留独立来源。
- Reward 使用冻结的 **`delivery-bonus-50-v1`**，通过工作区 `task_reward` 逐题复算并核对原分。完整性交付失败计零。难度分值乘以两项等权得分，即严格通过与登记核心检查通过率。下文 API 仅使用核心转换用例 A 组。
- 完整 E2E 采用 Harbor 的试次起止时间，含准备、解题和评分。超时按真实耗时保留并另标。输入、输出和总 tokens、USD 只累计所选试次的已结算模型请求，已结算的重复发送照实纳入该次成本和耗时。两边统一按冻结峰时费率估算，缓存未命中输入、缓存命中输入、输出分别为 **$1.32、$0.044、$3.96／百万 tokens**。成本是估算，旧试点和被替换的六次运行另有实际消耗。
- 子 Agent 触发要求 trace 中同时有父子创建关系和子 Agent 自己的模型请求或工具活动。旧版 Worker 由调度器启动，官方版使用 Supervisor 的交接机制。父级工具并行不计作子 Agent 启动。模型事件覆盖双方全部 59 题。

## 全部 59 组的结果

- **质量**　旧版 → 官方。Reward **47.048183 → 115.075909 / 138**，增加 **68.027726**。核心 API **382/803 → 747/803**，增加 **45.45 个百分点**。按题等权为 **43.80% → 92.13%**。公开检查 **27 → 58 题**，严格通过 **18 → 44 题**。Reward 有 **38 题提高、19 题持平、2 题下降**。
- **完整 E2E**　平均 **405.8 → 749.9 秒**，中位数 **339.7 → 429.9 秒**。官方版有 **40 题更慢、19 题更快**。C011、C009、MS12 三次 Agent 超时，加上 C039、C058 的两次传输重发异常，约占两版总 E2E 净差的 **68.1%**。
- **用量与成本**　输入 **20,944,753 → 34,261,455**，输出 **1,420,320 → 2,241,914**，合计 **22,365,073 → 36,503,369 tokens**。结算请求 **2,590 → 1,381**，每次请求平均 tokens **8,635 → 26,433**。统一峰时估算 **$9.624097 → $11.808171**，两侧选定试次均无未知用量。官方版有 **32 题成本更低、27 题更高**，总额受高成本长尾影响。
- **子 Agent**　实际工作的子 Agent 题数 **59/59 → 0/59**，工作者总数 **218 → 0**。官方全量中 **10 题触发了 15 次同会话续跑**。续跑属于对应原角色的后续请求。

两侧完整性均有效的 **52 题**中，核心 API 仍从 **382/734 提高至 685/734**。进一步要求旧版正常终态、官方侧无运行异常标签，剩余 **45 组**的核心 API 是 **340/640 → 601/640**，平均完整 E2E **404.5 → 462.5 秒**，总 tokens **17.903M → 22.159M**，成本 **$7.43 → $7.11**。这个事后筛选视图用于检查长尾和完整性失败的影响，主结果仍使用全 59 题。
